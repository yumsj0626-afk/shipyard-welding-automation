## 결정 기록 양식

각 ID 아래에 상태(미정/채택/보류/대체), 날짜, 결정자, 선택, 근거·공식 출처, 검토한 대안, 실험용 가정, 영향을 받는 모듈·데이터·검증, 재검토 조건을 추가한다. 이미 결정한 항목도 변경 이유를 남긴다.

실제 담당과 날짜는 아직 배정하지 않았다. 기준 문서의 승재(범위·통합), 승주(재계획·시뮬레이션·실험), 혜민(근거·사례·기록)은 역할 분담 제안이며 확정 일정으로 간주하지 않는다.
