# 기준 문서와 원본 보고서 설계 대조

2026-11-06 작성. B는 프로젝트 기준 문서 v1.0, R은 원본 중간보고서다. 정확한 파일 식별과 읽은 범위는 [출처 기록](sources.md)을 따른다. 이 표의 ‘유지’는 설계 원칙의 유지이며 구현 완료를 의미하지 않는다. 첨부 문서 안의 작업 요청 예시는 자료로만 읽었다. 최초 저장소 준비 이후 최신 사용자 요청에 따라 기술 선택·상세 계약까지 구체화했다. 아래 역사적 비교는 보존하고 현재 결정은 DEC 문서에 연결한다.

## 상세 결정과 남은 사항

최소 구현 기술·스키마·목적·자동 적용·실패·시간 규칙은 [DEC-01~06](decisions.md)에 개발 기본안으로 결정했다. 원본 파일·절 → 요구사항 → 선택 → 유지/변경 이유는 각 DEC와 [아키텍처](architecture.md)에 기록했다. 세부 필드는 [데이터 계약](data-contracts.md)이 기준이다.

가중 납기 지연과 변경량의 우선순위를 유지하고 무근거 유휴 방지 규칙을 개발 가정으로 추가했다. 원본의 미정 수치 승인 한도 대신 검사 통과한 실행 가능 해를 자동 적용한다. 원본 수치를 현장 측정값으로 승격하지 않는다. LLM 모델·예산, 본 평가 규모·반복·수치 통과 기준, OCR·3D·클라우드는 후속 결정으로 남긴다.
