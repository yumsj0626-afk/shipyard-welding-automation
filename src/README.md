# 구현 코드 위치

현재 실행 가능한 코드는 없다. 언어와 패키지 구조는 [결정 목록](../docs/decisions.md)의 DEC-01~03 이후 정한다. 다음은 책임을 나누기 위한 계획이다.

| 계획 모듈 | 입력 → 출력 | 권한과 경계 |
| --- | --- | --- |
| 상태·근거 저장 | 초기 데이터/검사된 갱신 → 현재 상태·근거·버전 | 코드만 쓰기. 계획 중 조회한 버전과 적용 시점 버전을 연결 |
| 정형 사건 검사 | 사건·현재 근거 → 검증된 사건 또는 부족/충돌 사유 | 필수 정보·ID·출처·현재성·중복 검사. 미확인을 사실로 채우지 않음 |
| 제한 관리·제약 변환 | 검증 사건·활성 제한 → 고정 규칙의 제약 | 원인별 제한을 유지하고 해당 복구 근거만 해제. 임의 코드·수식 수용 금지 |
| 일정 계산 | 현재 상태·제약·정책 → 후보 계획·해 상태 | 배정·순서·시간 계산. 상태 변경이나 실행 권한 없음 |
| 독립 실행 검사·적용 | 후보·최신 상태·정책 → 통과/거부·적용 기록 | 솔버 제약 생성과 별도 로직. 적용 시점 최신성·중복 실행 방지 |
| 경량 시뮬레이터 | 적용 지시·도착한 외부 신호 → 실제 시작/완료·관측 | 미래 사건은 시뮬레이터 내부에만 보유. 실제 설비 제어 없음 |
| 기록 | 입력·근거·제약·계획·검사·실행 → 추적 가능한 실행 기록 | 사건/실행 ID와 버전 연결. 외부 환경 신호와 추가 사람 요청 구별 |

문장형 보고 처리와 에이전트는 정형 최소 흐름 검증 후 추가한다. 이 문서에 등장하는 모듈은 생성되거나 동작하는 상태가 아니다.
